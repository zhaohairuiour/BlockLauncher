FAQ / 05

启动前先看这里

支持哪些 Android 设备？

当前构建只提供 arm64-v8a，最低 Android 8.0（API 26），目标 API 36。32 位设备或 x86 模拟器不在支持范围。

为什么 1.21.11 选 Java 21，而不是 Java 26？

1.21.11 的版本 JSON 要求 Java 21；Pojav 运行层稳定覆盖 Java 8 / 17 / 21。Java 24/26 属于实验性运行时，可能在 JLI_Launch 内直接退出，因此不会作为启动运行时自动选择。

更新需要卸载旧版吗？

不需要。所有版本使用同一签名证书，直接覆盖安装即可，账号、版本、存档会保留。

启动失败时日志在哪里？

启动器日志页会显示上次会话尾部；JVM 日志在应用外部目录 Android/data/com.blocklauncher.app/files/BlockLauncher/logs/。退出码和上次 JVM 尾部也会写入同一日志目录。

Bedrock 版是官方客户端吗？

启动器只负责检测和拉起设备上已安装的官方 Minecraft Bedrock 客户端，不提供客户端本体下载。
